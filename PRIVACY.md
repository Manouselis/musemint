# MuseMint privacy note

MuseMint collects no personal information and sends no data to a developer-controlled server. It has no analytics, ads, tracking pixels, or remote code.

Playlist data is processed transiently inside the active YouTube Music tab. If supported and enabled by Chrome, semantic reranking uses Chrome's on-device language model. A track is added only after the user clicks its **Add** button.

MuseMint communicates only with `music.youtube.com` using the session already active in that tab. Removing the extension removes its code and UI; it does not remove tracks previously added to playlists.
